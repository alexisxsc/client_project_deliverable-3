# UMSI Career Development Office Site

A responsive website built from scratch for the UMSI Career Development Office 
as a client project for SI 539: Web Design at the University of Michigan 
School of Information.

🌐 **[View Live Site](https://alexisxsc.github.io/client_project_deliverable-3/index.html)**


## About the Project

The UMSI Career Development Office (CDO) supports School of Information 
students with career resources, advising, and professional development. 
This project delivered a responsive, accessible website to communicate 
those resources clearly to students.

## What I Built

- Hand-coded in **HTML and CSS**
- **Responsive layout** using CSS Grid that adapts across desktop and mobile viewports
- **Accessible design** following WCAG principles: semantic HTML, sufficient color contrast, and keyboard-navigable structure
- Deployed via **GitHub Pages**

## Tech Stack

`HTML` · `CSS` · `CSS Grid` · `GitHub Pages`

## Context

Built as a client project for SI 539: Web Design (Winter 2026), University 
of Michigan School of Information.
